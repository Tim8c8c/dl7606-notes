# DASC7606 Deep Learning study notes

Mobile-friendly study notes for HKU DASC7606 (lectures 1–7): mind maps, interactive demos, recall quizzes, flashcards and three practice papers.

Open `index.html`, or visit the GitHub Pages site once it's enabled (Settings → Pages → Deploy from branch `main`, folder `/ (root)`).

Progress, quiz scores and flashcard marks are saved in your browser only.
