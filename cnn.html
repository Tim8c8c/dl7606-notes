Convolutional networks卷積神經網絡

The CNN arithmetic that appears in every paper, and the architectures that won ImageNet.

01The four formulas you must know02Convolution layer03Pooling and dense layers04ImageNet and the famous architectures✓Recall check

A CNN (LeNet 1998) has two parts: feature extraction (convolution + pooling layers) and classification (fully connected layers). Inspired by Hubel & Wiesel (1959): simple cells in the visual cortex respond to basic stimuli, later stages combine them.

01The four formulas you must know四條必背公式

Output size: M = ⌊(N + 2P − F) / S⌋ + 1 (also for pooling) "Same" conv: S = 1 and P = (F − 1)/2 (3×3 → P=1, 5×5 → P=2, 7×7 → P=3) Parameters: K filters × (F·F·C_in + 1) (+1 = bias; pooling has 0 params) Multiplications: M·M·K × F·F·C_in (= number of connections, no bias) FC layer: params = (n_in + 1)·n_out ; mults = n_in·n_out
Local receptive field (LRF 局部感受野), tracked layer by layer with "jump" j: start: r = 1, j = 1 conv/pool with filter F, stride S: r ← r + (F − 1)·j , j ← j·S e.g. conv3(s1) → r=3 ; pool2(s2) → r=4, j=2 ; conv3 → r=4+2·2=8 ; pool2 → r=10, j=4 Three stacked 3×3 convs (stride 1): r = 3 → 5 → 7 = one 7×7 conv

02Convolution layer卷積層

Why convolution instead of fully connected?

  • 100×100 image fully connected to 100×100: 100M connections. A 5×5 filter: 25 params, 250K connections (400× fewer).
  • Only nearby pixels matter; the same detector works on every patch.
  • Translation invariance 平移不變: same filter finds the pattern anywhere → needs fewer training samples.
  • Hierarchy: low layers learn edges/lines, middle layers circles and parts, high layers wheels, faces, objects.
  • A colour filter covers all channels: 5×5×3 = 75 weights. K filters → K output channels (depth K).
  • Padding 填充: valid (no padding, image shrinks), same (size kept), full (every pixel in F² LRFs). Without padding the image shrinks each layer, limiting depth, and border pixels are under-represented.
  • ReLU after conv: cheap, no vanishing gradient, and it makes colour changes (edges) more abrupt.
  • Filter purpose: a filter is a template; output is a dot product |u||v|cos θ, largest when the patch looks like the filter. Rows [−1,−1,−1; 0,0,0; 1,1,1] detect horizontal edges; columns [−1,0,1] detect vertical edges.

03Pooling and dense layers池化層與全連接層

  • Max pooling outputs max of the window; average pooling outputs the mean; L2 pooling outputs √ΣA². Usually 2×2, stride 2 (non-overlapping). S < F means overlapping pooling (AlexNet: 3×3, S=2).
  • Why pool: fewer values (2×2 cuts by 4×) → less memory, faster, less overfitting; later layers see larger windows; small shifts don't change the output (location invariance). No parameters, no multiplications.
  • A 2×2 pool after a 3×3 conv makes the LRF 4×4, not 6×6: it does not double.
  • Dense layers at the end aggregate the features. Flattening W×H×D → W·H·D numbers loses location, which is fine: head + tail + legs ⇒ cat.
  • 3D CNN: cube kernels over volumes (CT/MRI) or video (time as 3rd axis).

04ImageNet and the famous architectures經典網絡架構

ILSVRC: 1.2M images, 1000 classes, top-5 error. Human ≈ 5.1%. Shallow (28.2%, 25.8%) → AlexNet 2012 (16.4%, 8 layers) → ZFNet 2013 (11.7%) → VGG 2014 (7.3%, 19 layers) → GoogLeNet 2014 (6.7%, 22 layers) → ResNet 2015 (3.57%, 152 layers).

NetKey ideas 重點
AlexNet 2012~60M params, 650K neurons. ReLU, dropout on FC, overlapping max pool 3×3 S2, data augmentation, 2 GPUs (layers split in 2 groups). 227×227×3 → conv 96 11×11 S4 → 55×55 → pool → 27 → conv 256 5×5 P2 → pool → 13 → 384, 384, 256 3×3 → pool → 6×6×256 = 9216 → FC.
ZFNet 2013Tuned AlexNet: conv1 11×11 S4 → 7×7 S2; more filters in conv3–5. Main contribution: visualising what each layer learns (deconvolution).
VGG 2014Only 3×3 convs. Regular: halve size, double channels. Three 3×3 layers = LRF of one 7×7 but 3·(9C²) = 27C² < 49C² params, and 3 non-linearities instead of 1. ~138M params, most in FC.
GoogLeNet 2014Inception: 1×1, 3×3, 5×5 convs and pooling in parallel; the net picks the best size. 1×1 bottleneck cuts channels before big filters. No FC layer: global average pooling. Auxiliary classifiers mid-network inject gradient (helps vanishing gradient). 22 layers, ~4M params (12× fewer than AlexNet).
ResNet 2015Deeper plain nets got worse (degradation), even though extra layers could in theory be identity. Residual block: output = F(x) + x, so a layer only learns the residual F(x) = H(x) − x; learning F = 0 is easier than learning identity. Skip connections pass gradients straight back. 152 layers; bottleneck 1×1 (256→64) → 3×3 → 1×1 (64→256).
Hyper-connections 2025Widen the residual path into several parallel streams that layers mix (multi-lane highway); risk of unstable training, DeepSeek constrains mixing with softmax.
ReduNet 2022"White-box" network: each layer is derived from maximising rate reduction ΔR = R − R_c: expand between classes, compress within a class into a low-dimensional subspace.

1×1 convolution cost saving (GoogLeNet slide, worth memorising)

28×28×192 → 5×5 conv, 32 filters: (5·5·192)·(28·28·32) ≈ 120.4 M mults with 1×1 to 16 channels first: (1·1·192)·(28·28·16) + (5·5·16)·(28·28·32) = 2.41 M + 10.04 M ≈ 12.4 M mults (about 10× cheaper)
中文重點

輸出尺寸 M = (N + 2P − F)/S + 1；參數 = 濾波器數 ×（F×F×輸入通道 + 1）；乘法次數 = 輸出元素數 × F×F×輸入通道。池化層冇參數。VGG 用三層 3×3 代替一層 7×7（感受野相同、參數較少、非線性較多）。GoogLeNet 用 1×1 卷積減少通道（瓶頸層）、全域平均池化、輔助分類器。ResNet 用殘差連接 F(x)+x，令梯度直接回傳，可以訓練 152 層。

Recall check即時測驗

Output size for N = 32, P = 0, F = 5, S = 1?

(32 + 0 − 5)/1 + 1 = 28.

Parameters of 16 filters 3×3 on 8 input channels (with bias)?

16 × (3·3·8 + 1) = 1,168.

How many parameters does a 2×2 max-pool layer have?

Pooling has nothing to learn.

Three 3×3 conv layers (stride 1) have the same receptive field as one…

3 → 5 → 7. And 27C² < 49C² parameters.

GoogLeNet's 1×1 convolutions mainly…

Bottleneck: 192 → 16 channels before the 5×5 conv cuts cost ~10×.

ResNet blocks learn…

Output F(x) + x; learning F = 0 is easy and gradients flow through the skip.
