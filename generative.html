01Topic guide課題導讀（中文解釋＋例子）

Lecture 9 · Deep generative models outline. Tap a topic for a Traditional Chinese explanation and an example. The English notes below go into exam detail.

1DeepDreamDeepDream

固定一個訓練好的 CNN，修改輸入圖片令某層神經元的激活值最大（梯度上升），把網絡「看到」的圖案放大，產生夢幻效果。

例子用 ImageNet（很多狗和鳥的圖）訓練的網絡做 DeepDream，雲朵裡會「浮現」狗頭和鳥。

2Style transfer風格轉移

輸出圖 x 要有內容圖 p 的內容和風格圖 a 的風格。內容損失：x 與 p 在某層特徵的均方誤差；風格損失：比較兩者的 Gram 矩陣（特徵之間的相關性 = 紋理）。總損失 = α·內容 + β·風格，對像素做梯度下降。

例子把你的維港相片（內容）配上梵高《星夜》（風格）：α/β 越大，越像原相；越小，筆觸越明顯。

3Autoencoder自編碼器

編碼器把 x 壓縮成較低維的潛在向量 z，解碼器再還原成 x′，訓練令 x′ ≈ x（重建損失）。不用標籤（非監督）。用途：逐層預訓練網絡、去噪自編碼器 (DAE) 修復損壞圖片、把編碼器接上 softmax 做分類器、稀疏自編碼器找可解釋特徵。

例子784 像素的手寫數字壓縮成 32 個數字，再還原成 784 像素；去噪版本：輸入加了雜點的圖，目標是原本乾淨的圖。

4Variational autoencoder (VAE)變分自編碼器

普通自編碼器的潛在空間有空隙，隨便取一點解碼出來是垃圾。VAE 的編碼器輸出平均值 μ 和標準差 σ（一個分佈），損失 = 重建損失 + KL 散度（令分佈接近標準常態）。潛在空間變得連續、完整，可抽樣生成新數據。

例子在「3」和「8」的潛在向量中間取一點，VAE 會解碼出一個介乎 3 和 8 之間、從未出現過的數字。缺點：生成的圖較模糊（學的是「平均」）。

5Generative adversarial network (GAN)生成對抗網絡

生成器 G 把隨機噪聲 z 變成假樣本；判別器 D 判斷樣本是真是假（輸出 0–1）。D 想 D(x) → 1、D(G(z)) → 0；G 想 D(G(z)) → 1。兩者輪流訓練（min_G max_D 遊戲），直到 D 只能輸出 0.5。問題：模式崩潰、不收斂、扭曲圖像。

例子偽鈔集團（G）與警察（D）：警察越識分真假，偽鈔就越逼真。假圖得 D = 0.4：訓練 D 的損失 −ln 0.6 = 0.51；訓練 G 的損失 −ln 0.4 = 0.92。

6Conditional GAN條件式 GAN

普通 GAN 不能指定生成甚麼。C-GAN 在 G 和 D 的輸入都加上標籤 N（經嵌入層），G 學生成「指定類別」的樣本，D 判斷「這是不是真的 N 類樣本」。需要標籤，所以不是完全非監督。

例子輸入標籤「7」→ 生成手寫的 7；輸入「連身裙」→ 生成連身裙圖片。

7Pix2PixPix2Pix 圖對圖翻譯

C-GAN 的應用：以一張輸入圖 N 為條件，生成器（U-Net）輸出翻譯後的圖 G(N)；判別器看 (N, 真圖 x) 或 (N, G(N)) 判斷真假。需要「成對」的訓練數據。

例子黑白相 → 彩色相、草圖 → 手袋照片、衛星圖 → 地圖、白天 → 夜晚。

8CycleGANCycleGAN

不需要成對數據。兩個生成器（X→Y、Y→X）和兩個判別器。循環一致性：X 轉成 Y 再轉回 X，應該得回原圖。擅長改顏色和紋理，不擅長改形狀。

例子馬 ↔ 斑馬、相片 ↔ 莫奈油畫、夏天 ↔ 冬天。蘋果 → 橙通常失敗（形狀要變）；訓練集沒有人騎馬的圖，所以騎士也會被塗上斑馬紋。

9Stable DiffusionStable Diffusion（擴散模型）

列在大綱中，但本講義未有詳細投影片。一般概念：訓練時逐步向圖片加噪聲，模型學習每一步如何去噪；生成時由純噪聲開始，按文字提示一步步去噪成圖片。

例子文字提示「穿實驗袍的貓科學家」→ 由一片雪花雜訊，經數十步去噪，變成一張清晰圖片。（等下一講確認細節。）

10Vision Transformer (ViT)視覺 Transformer

把圖片切成 16×16 的小方塊，每塊當作一個「字」，加位置嵌入後送入 Transformer 編碼器分類。全域注意力一開始就看到整張圖；數據越多表現越好，在超大數據集預訓練後勝過 CNN。

例子224×224 的圖切成 (224/16)² = 196 個方塊，等於一句有 196 個字的句子。

11CLIPCLIP 對比式圖文預訓練

用 4 億對「圖片–文字說明」訓練兩個編碼器（圖片用 ResNet、文字用 GPT-2 類模型）。對比學習：配對的圖文向量相似度要高，不配對的要低。之後可零樣本分類：把每個類別寫成「a photo of a ___」，選與圖片餘弦相似度最高的。

例子一張戴冷帽女孩的相：「A girl wearing a beanie」90%、「a hat」9%、「a dog」0%。不用重新訓練，就可以分類從未見過的類別。

02DeepSeek, continuedDeepSeek（續）

Mixture of Experts (MoE) 混合專家

In each transformer block the single feed-forward network (FFN) is replaced by many smaller expert FFNs plus a router that sends each token to only its top-k experts. DeepSeekMoE uses fine-grained experts and always-on shared experts. Total parameters are huge (671B) but each token uses only a small fraction, so compute stays low.

DeepSeek-R1-Zero: pure RL (like AlphaGo Zero)

Start from V3-Base and train with GRPO (Group Relative Policy Optimization): for each question generate k outputs, score each with rule-based rewards (accuracy of the answer, correct format with <think>…</think><answer>…</answer>), and push the model towards the better-than-average ones. No human feedback needed. Its responses grow longer during training, and it shows an "aha moment" where it stops and re-checks its reasoning.

R1 stageWhatWhy
[1] SFTFine-tune V3-Base on high-quality, readable R1-Zero outputs ("cold start")Fix R1-Zero's poor readability and language mixing
[2] RLGRPO on maths, programming and logic with rule-based rewardsReinforce good reasoning
[3] SFTModel [2] generates many samples; keep only correct, readable ones (checked with V3); add V3's non-reasoning dataGood at both reasoning and general tasks
[4] RLGRPO on diverse tasks: rule rewards where possible, LLM feedback for human preference otherwiseBehave well in all scenarios

Pipelines: R1-Zero = pre-training → RL. R1 = pre-training → SFT → RL → SFT → RL. Distillation: smaller open models (Qwen, Llama) were fine-tuned with SFT only on 800k R1 samples, giving strong small reasoning models.

04DeepDreamDeepDream

Google, built on the gradient ascent visualisation from lecture 4. Choose an image I and a trained CNN. Let f_x(I) be the activation of neuron x in layer L. Fix the weights, feed I forward to layer L, back-propagate to the pixels, and change I to maximise f_x(I). Whatever the neuron "sees" gets exaggerated.

  • Lower-layer neurons → strokes and textures; higher layers → more sophisticated objects.
  • Trained on ImageNet (many dogs and birds), so dogs and birds keep popping up.

05Neural style transfer神經風格轉移

Gatys et al. 2016: make an output image x with the content of image p and the style (texture) of image a. Key idea: a pre-trained CNN separates content from style.

Content loss (layer l): L_content = ½ Σ (F_ij(x) − P_ij(p))² F = features of x, P = features of p Gram matrix (layer l): G_ij = Σ_k F_ik F_jk N×N, N = number of feature maps (each M×M) dot product of feature maps i and j = how often they fire together = texture Style loss (layer l): E_l = 1/(4N²M⁴) Σ (G_ij(x) − A_ij(a))² ; L_style = Σ_l w_l E_l Total: L = α·L_content(p, x) + β·L_style(a, x) → gradient descent on the PIXELS of x

Tiny Gram example

Three feature maps flattened to 4 values: F₁ = [1,0,2,1], F₂ = [0,1,1,0], F₃ = [2,2,0,1].

G = [[6,2,3], [2,2,2], [3,2,9]] G₁₃ = 1·2 + 0·2 + 2·0 + 1·1 = 3

Controls

  • α/β larger → more content kept; smaller → more style.
  • Spatial control: different styles for different regions (e.g. sky vs ground).
  • Colour control: keep the content image's colours, via luminance-only transfer or colour-histogram matching.

06Autoencoders自編碼器

UseHow
1. Pre-train deep networksGreedily train a stack of shallow autoencoders one layer at a time on unlabelled data; then fine-tune the last layer, then the whole network, on labelled data.
2. Denoising autoencoder (DAE)Add noise / zero out random inputs on purpose; the loss compares the output with the original clean input, not the corrupted one. Recovers corrupted images.
3. ClassifierTrain an autoencoder, remove the decoder, add a sigmoid/softmax layer, train only that layer with encoder weights frozen. The encoder is a feature extractor.
Sparse autoencoder (SAE)Add a sparsity penalty: L = ‖x′ − x‖² + λ·penalty(z) (e.g. L1), so only a few hidden units fire (like the brain). Prevents overfitting and gives interpretable features; used to interpret language models (2023).

07Variational autoencoder (VAE)變分自編碼器

Problem: a plain autoencoder's latent space has distinct clusters with gaps. Great for reconstructing, bad for generating: decode a point in a gap and you get nonsense.

A VAE wants a latent space with continuity (nearby points decode to similar content) and completeness (any sampled point decodes to something meaningful).

How

  • The encoder outputs two vectors of size n: a mean μ and a standard deviation σ; sample z ~ N(μ, σ²).
  • AE learns a compressed representation; VAE learns the parameters of a probability distribution, so it can sample new data.

Loss

Loss = reconstruction loss + KL divergence = −E_z[log p(x|z)] + D_KL(q ‖ p)

KL alone piles all encodings at the centre (useless). Both together give smooth, well-separated clusters, so interpolating between "3" and "8" produces in-between digits that never existed.

Weakness: VAE learns an "averaged" representation, so generated images are blurry. That motivates GANs.

08Generative adversarial networks (GAN)生成對抗網絡

ComponentFunctionInputOutput
Generator GCreate realistic synthetic samples to fool D (a counterfeiter)Random noise vector z (plus a label for conditional GAN)Synthetic sample, e.g. an image

Loss: binary cross-entropy (= binary logistic loss) min_G max_D E[log D(x)] + E[log(1 − D(G(z)))] D training: real x → target 1 : loss = −log D(x) fake → target 0 : loss = −log(1 − D(G(z))) G training: fake → target 1 : loss = −log D(G(z)) (D frozen; gradient flows through D into G)

Real image, D outputs 0.7

Only D learns from it (G was not involved). Target 1, loss = −ln 0.7 = 0.357. Backprop pushes D's output towards 1.

Fake image, D outputs 0.4 (or 0.2)

D step: target 0, loss = −ln(1 − 0.4) = 0.511; push towards 0. G step: freeze D, target 1, loss = −ln 0.4 = 0.916; update G's weights so D's score rises. For 0.2: D loss 0.223, G loss 1.609 (G is losing badly, big gradient).

  • Training alternates: train D for a step (or k steps) on real + fake, then train G with D frozen. With a generated sample, either G or D is trained in a given step: D with target 0, G with target 1.
  • Challenges: mode collapse (G produces few varieties); non-convergence / oscillation; vanishing gradient when D becomes too good; balancing D and G; no simple metric of quality; sensitive to hyper-parameters; high compute.
  • Variation of samples comes from the random input z (and the label in a conditional GAN). Mode collapse is the failure of variation.
  • Turing-test analogy: D plays the interrogator, G the machine. G succeeds when D can't do better than guess (outputs 0.5 everywhere).
  • Colourising B/W photos: a conditional GAN (pix2pix-style) with an encoder–decoder (U-Net) generator. Input greyscale, output colour; skip connections keep edges sharp; D judges whether the colour looks plausible.
Discriminator: max_D log D(x) + log(1 − D(G(z))) (D(x) → 1, D(G(z)) → 0) Generator: min_G log(1 − D(G(z))) (wants D(G(z)) → 1) Together: min_G max_D E_x~R[log D(x)] + E_z[log(1 − D(G(z)))] for each iteration: for k steps: sample m noise z and m real x; update D by ASCENDING ∇θ_D (1/m)Σ[log D(xᵢ) + log(1 − D(G(zᵢ)))] sample m noise z; update G by DESCENDING ∇θ_G (1/m)Σ log(1 − D(G(zᵢ))) At the optimum the fake distribution F matches the real one R and D outputs 0.5.

Lecture's three problems: mode collapse (real data has several modes and G learns just one: "easier to be an expert on one than a jack of all trades"), non-convergence (a zero-sum minimax game can oscillate) and distorted figures.

10Vision Transformer (ViT)視覺 Transformer

  • Split the image into fixed-size 16×16 patches, linearly embed each, add position embeddings, add a class token, and feed the sequence to a transformer encoder; an MLP head classifies.
  • A 224×224 image → (224/16)² = 196 patch tokens.
  • Why it excels: global attention sees the whole image from layer 1 (CNNs only approximate that after many layers), and it scales: modest on mid-sized data, excellent after pre-training on massive data. Its share of papers rose sharply after 2021.

11CLIP: Contrastive Language–Image Pre-trainingCLIP 對比式圖文預訓練

  • OpenAI, open source, multimodal (text + vision), zero-shot (handles labels it was never trained on). Trained on 400 million image–text pairs from the internet; captions say more about a scene than manual labels.
  • Contrastive pre-training: a text encoder (GPT-2-like) and an image encoder (ResNet or ViT) each output a d-dim vector. For a batch of N pairs, compute the N×N cosine-similarity matrix; maximise the diagonal (matching pairs), minimise the off-diagonal (non-matching), using symmetric cross-entropy.
  • Zero-shot classification: write one prompt per class ("a photo of a dog", "a photo of a cat"…), encode them, encode the image, pick the prompt with the highest cosine similarity.
  • K-shot learning: K examples per class. Few-shot K < 10, one-shot K = 1, zero-shot K = 0.
  • Impact: robust to distribution shift (ImageNet sketches, adversarial sets), and zero-shot CLIP beats many few-shot classifiers.

12Exam-style practice考試式練習

1. (Dec 2025 Q3 style) A real image gives D = 0.7; a generated image gives D = 0.4. Describe the training for each.

Show answer

Real, 0.7: only D is trained, target 1, loss −ln 0.7 = 0.357; backprop raises D(x). Fake, 0.4: D step with target 0, loss −ln(1 − 0.4) = 0.511 (push towards 0). G step with D frozen, target 1, loss −ln 0.4 = 0.916; gradients flow through D into G so its next samples score higher.

2. Why are VAE samples better than plain-autoencoder samples, but GAN samples sharper than VAE samples?

Show answer

A plain AE's latent space has gaps, so random points decode to nonsense. The VAE's KL term makes the space continuous and complete, so any sample decodes to something meaningful. But the VAE's reconstruction loss averages over possibilities, giving blurry images; a GAN's generator is judged by a discriminator that punishes anything that doesn't look real, so outputs are sharper.

3. You have 5,000 summer photos and 5,000 winter photos of different places. Pix2Pix or CycleGAN?

Show answer

CycleGAN: the photos are unpaired (not the same scene before and after). Pix2Pix needs paired images. CycleGAN uses two generators, two discriminators and a cycle-consistency loss.

4. In style transfer, what is optimised, and what does the Gram matrix capture?

Show answer

The pixels of the output image x (the CNN's weights are fixed), minimising α·content loss + β·style loss. The Gram matrix holds dot products between feature maps in a layer: which features fire together, i.e. texture and style regardless of position.

5. How does CLIP classify an image into classes it was never trained on?

Show answer

Write a text prompt per class ("a photo of a {class}"), encode each with the text encoder, encode the image with the image encoder, and choose the class whose text embedding has the highest cosine similarity with the image embedding. No extra training: zero-shot.
