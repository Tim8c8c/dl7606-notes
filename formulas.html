Traps that cost marks
  • Forgetting the +1 bias per filter in parameter counts (but not in multiplication counts).
  • Forgetting the input depth C_in in the filter size: a 3×3 filter on 192 channels is 3×3×192.
  • Giving pooling layers parameters. They have none.
  • Using log base 10. Use natural log (ln) for cross-entropy unless told otherwise.
  • Forgetting to scale by √d_k when the question says "scaled dot-product attention", or adding it when the question says plain dot product.
  • For "explain" questions: give the mechanism and the consequence (e.g. "σ' ≤ 0.25 multiplies at every layer → gradient shrinks exponentially → early layers stop learning").

Recall check即時測驗

Conv multiplications formula?

Output size × filter volume. No bias term.

FC layer 784 → 10 parameters?

(784 + 1) × 10.

Weight memory for P params at b bits?

8 bits = 1 byte.
