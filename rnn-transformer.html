1Recurrent neural networks (RNNs)循環神經網絡

處理有次序的序列：s_t = g(Wx_t + Us_{t−1})，每一步把上一步的狀態傳下去，權重在每一步共享，所以可處理任意長度。缺點：慢、不能看未來、會忘記很久以前的資訊。

例子「食物好好味，一啲都唔難食」vs「食物好難食，一啲都唔好味」：字差不多但次序不同，RNN 能分辨情感。

2Long short-term memory (LSTMs)長短期記憶網絡

用三個閘控制記憶：遺忘閘丟掉無關舊資訊、輸入閘選擇寫入新資訊、輸出閘決定輸出哪部分。解決 RNN 的遺忘問題。

例子「Grace 肚餓……Beth 帶了曲奇回家，她不餓……曲奇被 ___ 吃了」：LSTM 要記住「她」指的是誰，並在出現新角色時更新。

3Word embedding (CBOW, Skip-gram, ELMo)詞嵌入

把字變成向量，意思相近的字向量相近。CBOW 用上下文預測中間字；Skip-gram 用中間字預測上下文；ELMo 按上下文即時產生向量，解決一字多義。

例子king − man + woman ≈ queen。CBOW 訓練例子：輸入 {My, cat, on, the} → 預測 "sits"。

4Seq2Seq: machine translation序列到序列：機器翻譯

編碼器把整句讀成一個向量，解碼器再逐字生成譯文。同一編碼器可接不同語言的解碼器，亦可用於聊天機械人和圖片說明。

例子"He likes to eat" → 編碼成向量 → 解碼出「他 喜歡 吃」。

5Attention注意力機制

固定長度的向量記不住長句。注意力讓解碼器每一步都回望所有編碼狀態，按相關程度加權：α = softmax(分數)，context = Σ α·h。

例子翻譯「吃」時，模型把大部分注意力放在 "eat" 上，而不是 "He"。

6TransformerTransformer

完全用注意力，不用循環。編碼器用自注意力；解碼器用遮罩自注意力（不准偷看未來）和編碼器–解碼器注意力。可平行計算，訓練時用教師強制。

例子「The cat drank the milk because it was hungry」：自注意力令 "it" 主要關注 "cat"；如果句尾是 "sweet"，就關注 "milk"。

02Recurrent neural networks循環神經網絡

Pros

  • Input of any length
  • Weights shared over time
  • Uses history

Cons

  • Slow, sequential (no parallelism)
  • Can't see future input (→ bidirectional RNN)
  • Forgets the distant past (→ LSTM, attention)

Designing an RNN by hand (C-section style)

With identity activation, the state update is linear: s_t = W x_t + U s_{t−1} + b. To keep a running sum put 1 in W and 1 on U's diagonal; to keep a counter t use W = 0, U = 1, b = 1. Running mean = sum / counter. For x ∈ {0,1}, x² = x, so a sum of squares is just another sum. For x ∈ {0,2}, x² = 2x; for x ∈ {1,2}, x² = 3x − 2 (fit a line through the two allowed points).

03LSTM長短期記憶網絡

forget gate f_t = σ(W_f·[y_{t−1}, x_t]) drop irrelevant parts of old state (e.g. old gender) input gate i_t = σ(W_i·[y_{t−1}, x_t]) candidate C̃_t = tanh(W_C·[y_{t−1}, x_t]) state s_t = f_t ∗ s_{t−1} + i_t ∗ C̃_t selectively update ("+" path keeps gradients alive) output gate o_t = σ(W_o·[y_{t−1}, x_t]) , y_t = o_t ∗ tanh(s_t) output part of the state

Three gates: forget, input, output (May 2024 D asked exactly this). Example: "Grace was hungry… Beth… she… The cookies were eaten by __": the cell must update who "she" is.

04Word embeddings詞嵌入

  • One-hot (local): N-dim vector, one 1. Huge (N ≈ 100K) and every pair of words is equally unrelated.
  • Distributed: dense k-dim real vector; dimensions behave like features (royalty, gender, age). Similar words → nearby vectors. Distributional hypothesis: "you shall know a word by the company it keeps."
  • Count-based: word–document matrix, window co-occurrence matrix.
CBOW steps (N words, k-dim vectors, m context words) 1. X = 1×N with m ones (bag of context words) 2. ṽ = X·U / m average of the m context word vectors (1×k) 3. s = ṽ·U' score for every vocabulary word (1×N) 4. ŷ = softmax(s) probabilities 5. loss = −log ŷ[true centre word] backprop updates U and U'
  • Quality depends on model, vector size (too small and too large both hurt), window size, corpus size and domain. Ambiguous words (share, run) get one blurred vector.
  • Evaluation: intrinsic (similarity, analogies: boy:girl = king:queen; good:best = bad:worst; walking:walked = going:went) vs extrinsic (accuracy on a downstream task such as NER or sentiment; slow and hard to attribute).
  • ELMo: 2-layer bidirectional LSTM trained to predict next and previous words on 5B words. Context-sensitive: "trust" in "can't trust you" vs "trust fund" gets different vectors. ELMo_k = s₀x_k + s₁h₁,k + s₂h₂,k with task-specific weights.

05Seq2Seq and attention序列到序列與注意力機制

Machine translation history: rule-based (1950) → statistical (1990) → neural (2015). Encoder reads "He likes to eat" into a state vector (sentence embedding); decoder generates 他 喜歡 吃 one word at a time. The same encoder can feed several decoders (French, Chinese, Japanese), a vision encoder can feed a text decoder (captioning), and a chat log can train a support bot.

Problem: one fixed vector forgets long sentences. Attention: at each decoder step t, score every encoder state hᵢ, softmax the scores, and use the weighted sum as context.

e_ti = a(s_{t−1}, h_i) alignment score (a small NN) α_ti = softmax_i(e_ti) attention weights, sum to 1 c_t = Σ_i α_ti · h_i context vector fed to the decoder

06Transformer (Google, 2017)Transformer 架構

Attention step by step 注意力計算

Q = XW_Q, K = XW_K, V = XW_V scores = Q·Kᵀ (dot product = similarity) scale ÷ √d_k (keep softmax from saturating) A = softmax(row-wise) (each row sums to 1) out = A·V (weighted average of values)
  • Q (query): what this word is looking for.
  • K (key): the label each word advertises.
  • V (value): the content handed over when matched.
  • Multi-head: several W_Q, W_K, W_V sets, each attending to a different relation (e.g. "state" vs "taste"), outputs concatenated.
  • "it" attends to "cat" in "…because it was hungry" and to "milk" in "…because it was sweet".
Sinusoidal positional encoding (E = embedding size): PE(pos, 2i) = sin(pos / 10000^(2i/E)) PE(pos, 2i+1) = cos(pos / 10000^(2i/E)) input to encoder = word embedding + positional encoding (N tokens × E)

Inference (translation) 推理

  1. Encode the source once.
  2. Decoder starts with <s>.
  3. Take the predicted word, append it to the decoder input.
  4. Loop until <eos>.

Training: teacher forcing 教師強制

Feed the correct target, shifted right, in one pass. Word i is predicted from true words 1…i−1, so errors don't compound and all positions train in parallel. The mask in decoder self-attention hides future words so the model can't peek.

Transformer vs RNN/LSTM (Dec 2024 Q5)How the transformer fixes it
Long-range dependencies: RNN forgets distant tokensSelf-attention connects every pair of tokens directly (path length 1)
Sequential processing: no parallelism, slowAll tokens processed at once; no recurrence, better gradient flow
Fixed-size state/embedding bottleneckEach token keeps its own E-dim context-aware embedding through every layer
Shortcomings: cost O(n²) in sequence length (memory and time); fixed context window; needs huge data and compute; position must be added explicitly; hard to interpret.
Q/K/V analogies (Dec 2024 Q5c)
  • Supermarket: Q = the item name on each person's list, K = shelf labels, V = the items on the shelf.
  • Uber: Q = passenger's location/request, K = each car's location, V = the car (driver) that gets assigned; the nearest car gets the most attention.
中文重點

RNN 權重跨時間共享，但計算慢、會遺忘長距離資訊；LSTM 用遺忘閘、輸入閘、輸出閘解決。CBOW 用上下文預測中心詞，Skip-gram 用中心詞預測上下文。注意力：分數 = Q·Kᵀ，除以 √d，softmax 後與 V 加權平均。Transformer 冇遞歸，可平行計算；解碼器用遮罩隱藏未來詞；訓練用教師強制；編碼器–解碼器注意力中 Q 來自解碼器，K、V 來自編碼器。
