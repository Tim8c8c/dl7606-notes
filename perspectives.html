1History of AI人工智能簡史

AI 是大範圍，機器學習 (ML) 是 AI 的一種方法，深度學習 (DL) 又是 ML 的一個分支。由早期人手寫規則，發展到由數據學習，再到用多層神經網絡自動學特徵。

例子想像三個同心圓：最外圈 AI（例如下棋程式），中間 ML（例如垃圾郵件過濾器），最內圈 DL（例如手機人臉解鎖）。

2Turing Test: imitation game圖靈測試

審問者 C 同時與機器 A 和人類 B 用文字對話。如果 C 分不出哪個是機器，就說機器表現出「智能」。早期聊天機械人 ELIZA 只靠捕捉關鍵字（如 "depressed"）就騙到不少人。

例子你在 WhatsApp 與兩個帳號聊天，一個是真人，一個是 ChatGPT。如果你猜錯哪個是 AI 的機會跟亂猜差不多，ChatGPT 就算通過了這個測試。

3Rule-based systems規則系統（專家系統）

由專家人手定義輸入特徵和 if-then 規則，例如醫療診斷、銀行批核貸款。優點是可解釋；缺點是要專家、難以覆蓋所有情況。

例子貸款規則：「如果月入 > 30,000 且沒有欠款紀錄，就批核」。遇到收入不穩定的自由工作者，規則就不知怎樣處理。

4Learning-based systems學習型系統

圖靈的想法：與其直接寫一個「成人的腦」，不如寫一個「小朋友的腦」，再透過教育（數據）令它慢慢變聰明。即由簡單程式開始，逐步改進。

例子小朋友學認貓：父母不會解釋「貓有鬍鬚、尖耳」，只是指著很多貓說「這是貓」，小朋友自然學會。

5Supervised learning監督式學習

用 (問題 x, 答案 y) 配對訓練模型 G，令 G 逼近未知函數 F。訓練集 = 練習題，驗證集 = 模擬試，測試集 = 正式考試。

例子用 (嬰兒月齡, 身高) 數據學到「身高 ≈ 0.7 × 月齡 + 63 cm」，再預測一個 25 個月大嬰兒約 80.5 cm。

6Deep learning vs machine learning深度學習 vs 傳統機器學習

傳統 ML 要人手設計特徵，模型只學「特徵 → 答案」。DL 直接由原始數據（像素、文字）學習特徵本身。

例子分辨貓狗：傳統 ML 要先人手量度「耳朵形狀、鼻子長度」；DL 直接吃整張相片，自己學出有用的特徵。

7Representation learning表徵學習

深度網絡每一層學一個抽象層次：低層學邊緣，中層學形狀，高層學物件。多層 = 多層次的抽象。

例子認人臉：第 1 層看到線條，第 3 層看到眼睛和鼻子，最後一層組合成「這是陳大文的臉」。

8The ABCDs of the journey成功四要素 ABCD

A = Algorithms（反向傳播、開源 PyTorch）、B = Big data（ImageNet 1,500 萬張圖）、C = Computing（GPU、雲端）、D = Dollars（大公司投資）。

例子神經網絡 1980 年代已有，但要等到有大量數據 + GPU + 資金，2012 年 AlexNet 才一鳴驚人。

B2Cost functions成本函數

Loss 是單一樣本的誤差，Cost J(θ) 是整個訓練集的平均誤差。迴歸常用均方誤差 MSE，分類用交叉熵 cross-entropy。

例子預測身高 80、實際 82 → 誤差平方 4；三個樣本誤差平方 4、1、0 → MSE = 5/3 ≈ 1.67。

B3Iterative guessing反覆猜測

先隨便猜一組參數 θ，計算誤差，然後不斷「猜得更好」直至誤差夠小。這就是學習的本質。

例子猜數字遊戲：猜 50，對方說「太大」，下次猜 25……每次根據回饋改進。

B4Gradient descent梯度下降

θ ← θ − α·∂J/∂θ。梯度（斜率）告訴我們誤差上升的方向，所以往相反方向走一步。α 是學習率（步長）。

例子J(θ) = θ²，θ = 3，α = 0.1：梯度 = 2θ = 6，新 θ = 3 − 0.6 = 2.4，越來越接近最低點 0。

B5Regression vs classification迴歸 vs 分類

迴歸輸出連續數值；分類輸出類別。分類其實常先輸出機率（迴歸），再用閾值決定類別。

例子迴歸：預測明天氣溫 27.3°C。分類：預測明天會否下雨（是/否）。

B6Logistic regression (binary classification)邏輯迴歸（二元分類）

先計分數 s = θx，再用 sigmoid σ(s) = 1/(1+e^−s) 變成 0–1 機率；> 0.5 判為正類。提高閾值 → 精確率上升、召回率下降。

例子s = 2 → σ = 0.88 → 預測「有心臟病」。疾病篩查寧願閾值低一點（高召回率），寧可多驗，不要漏網。

B7Multi-classification多類分類

用 softmax 把 K 個分數變成總和為 1 的機率，用分類交叉熵訓練。兩類時 softmax 等同 sigmoid。

例子手寫數字分數 [2, 1, 0.1] → softmax ≈ [0.66, 0.24, 0.10]，預測為第一類；如果真答案是第二類，loss = −ln 0.24 ≈ 1.42。

02From rules to representation learning由規則到表徵學習

  • Turing test (imitation game) 圖靈測試: an interrogator C questions a machine A and a human B. If C cannot tell which is the machine, the machine is "intelligent". ELIZA (first psychotherapy chatbot) faked it with keyword spotting.
  • Rule-based / expert systems 專家系統: an expert hand-writes facts and rules (diagnosis, loan approval). Needs an expert for both the features and the rules.
  • Learning-based: Turing: "simulate the child's mind, then educate it." Start simple and improve iteratively.
  • ABCD of the journey: Algorithms (backprop, open-source PyTorch/TensorFlow), Big data (ImageNet ~15M images, 22K categories), Computing (GPUs, cloud), Dollars (Google, Meta, OpenAI…).
  • Supervised learning: training data = practice exercises, validation = mock exams, test = final exam. Learn hypothesis G ≈ unknown F from pairs (x, y).

03Cost functions and gradient descent成本函數與梯度下降

Loss is for one example; cost J(θ) is the average loss over the whole training set.

MSE (L2): J(θ) = (1/M) Σ (h(xᵢ) − yᵢ)² (often ½ MSE: 1/(2M)) Absolute (L1): J(θ) = (1/M) Σ |h(xᵢ) − yᵢ| Binary CE: J = −[ y·log h(x) + (1−y)·log(1−h(x)) ] Categorical CE: J = −Σ_c y_c · log h_c(x) e.g. y=[0,1,0], h=[.94,.01,.05] → −log 0.01 Gradient descent: θ ← θ − α · ∂J/∂θ α = learning rate 學習率 Linear regression: ∂J/∂θⱼ = (1/M) Σ (h(xᵢ) − yᵢ)·xᵢⱼ Logistic regression gives the SAME update form (with h = σ(θx)).

Gradient intuition

  • Slope > 0 → θ decreases; slope < 0 → θ increases.
  • Steep slope → big step; flat slope → small step.

Regression vs classification 迴歸 vs 分類

  • Regression: continuous answer (height, rent, probability).
  • Classification: discrete answer (heart attack yes/no, digit 0–9).

04Logistic regression, softmax, metrics邏輯迴歸、Softmax、評估指標

σ(s) = 1 / (1 + e^(−s)) σ'(s) = σ(s)(1 − σ(s)) ≤ 0.25 Predict 1 if σ(s) > 0.5 ⇔ s > 0 softmax(s)_k = e^(s_k) / Σ_j e^(s_j) 2-class softmax = sigmoid of (s₁ − s₂) precision = TP / (TP + FP) recall = TP / (TP + FN) F1 = 2·P·R / (P + R) (harmonic mean punishes one extreme value)
  • Raise the threshold → fewer positives → precision ↑, recall ↓. Criminal prosecution wants high precision; disease screening wants high recall; terrorist identification wants both.
  • Why exponentials in softmax? They push the largest score towards 1 and the rest towards 0, and keep all outputs positive and summing to 1.
  • PR curve: area under it (AUC) high ⇒ both P and R high. Average Precision (AP) for detection is this area.
中文重點

監督式學習用 (x, y) 訓練假設函數 G ≈ F。成本函數：迴歸用均方誤差 (MSE)，分類用交叉熵 (cross-entropy)。梯度下降：θ ← θ − α∇J。提高閾值 → 精確率 (precision) 上升、召回率 (recall) 下降。Softmax 把分數變成總和為 1 的機率。

Recall check即時測驗

Raising the classification threshold usually…

Fewer things are called positive, so fewer false positives (precision ↑) but more missed positives (recall ↓).

Which cost function fits classification with a sigmoid output?

−[y log h + (1−y) log(1−h)]. MSE is for regression.

The gradient-descent update is…

Step against the slope; α is the learning rate.

Disease screening should prioritise…

Missing a sick patient (false negative) is the costly error.

F1 uses the harmonic mean because…

P = 1, R = 0.01 gives F1 ≈ 0.02, not 0.5.

What does 'D' stand for in the ABCD of deep learning's success?

Algorithms, Big data, Computing, Dollars.
