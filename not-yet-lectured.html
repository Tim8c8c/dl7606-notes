01Generative adversarial networks (GAN)生成對抗網絡

ComponentFunctionInputOutput
Generator GCreate realistic synthetic samples to fool D (a counterfeiter)Random noise vector z (plus a label for conditional GAN)Synthetic sample, e.g. an image
Discriminator DTell real from fake (the police); binary classifierA real or generated sampleProbability the input is real
Loss: binary cross-entropy (= binary logistic loss) min_G max_D E[log D(x)] + E[log(1 − D(G(z)))] D training: real x → target 1 : loss = −log D(x) fake → target 0 : loss = −log(1 − D(G(z))) G training: fake → target 1 : loss = −log D(G(z)) (D frozen; gradient flows through D into G)

Real image, D outputs 0.7

Only D learns from it (G was not involved). Target 1, loss = −ln 0.7 = 0.357. Backprop pushes D's output towards 1.

Fake image, D outputs 0.4 (or 0.2)

D step: target 0, loss = −ln(1 − 0.4) = 0.511; push towards 0. G step: freeze D, target 1, loss = −ln 0.4 = 0.916; update G's weights so D's score rises. For 0.2: D loss 0.223, G loss 1.609 (G is losing badly, big gradient).

  • Training alternates: train D for a step (or k steps) on real + fake, then train G with D frozen. With a generated sample, either G or D is trained in a given step: D with target 0, G with target 1.
  • Challenges: mode collapse (G produces few varieties); non-convergence / oscillation; vanishing gradient when D becomes too good; balancing D and G; no simple metric of quality; sensitive to hyper-parameters; high compute.
  • Variation of samples comes from the random input z (and the label in a conditional GAN). Mode collapse is the failure of variation.
  • Turing-test analogy: D plays the interrogator, G the machine. G succeeds when D can't do better than guess (outputs 0.5 everywhere).
  • Colourising B/W photos: a conditional GAN (pix2pix-style) with an encoder–decoder (U-Net) generator. Input greyscale, output colour; skip connections keep edges sharp; D judges whether the colour looks plausible.

Of the 15% chosen tokens, 80% become [MASK], 10% a random word, 10% stay unchanged, so the model can't rely on seeing [MASK] at test time.

Masking in the Transformer

Decoder self-attention uses a look-ahead mask: set scores to −∞ for future positions before softmax, so word i only sees words ≤ i. Also padding masks ignore pad tokens.

Masking in BERT

Training objective: hide 15% of input tokens and predict them from both sides of context. No look-ahead mask, which is why BERT is bidirectional.

03Hallucination and prompting幻覺與提示

Lecture 7 explains the sampling side of hallucination (the long tail); see chapter 08.

Why hallucinations happen 幻覺成因

  • The model predicts a plausible next token, not a true one; nothing checks facts.
  • Sampling from the distribution can pick a low-probability wrong token, and each later token builds on it (errors compound).
  • Training data is incomplete, outdated or contradictory; rare facts get low probability mass.
  • The model is trained to always answer, not to say "I don't know".

How to reduce them

  • Retrieval-augmented generation (RAG): fetch trusted documents and answer from them, with citations.
  • Lower temperature / greedy or top-k decoding.
  • Fine-tuning / RLHF that rewards "I don't know" and factuality.
  • Prompting: ask for sources, chain-of-thought, self-consistency checks; human or tool verification.

04Making LLMs smaller and cheaper模型壓縮：蒸餾、量化、LoRA

Parameter count (May 2025): P ≈ 2VE + L(4E² + 3EH + 2E) 2VE = input + output embedding 4E² = W_Q, W_K, W_V, W_O 3EH = MLP (gate, up, down) 2E = layer-norm weights V=32000, L=40, E=5120, H=13824 ⇒ P ≈ 13.0 B (MLP 3EH dominates: ~8.5 B) Memory to store weights = params × bits / 8 70 B × 4 bit = 35 GB 70 B × 16 bit = 140 GB 13 B × 8 bit = 13 GB LoRA: ΔW (d×k) ≈ A (d×r) · B (r×k) trainable params r(d + k) instead of dk four E×E matrices: 4E² → 4·2Er ; reduction factor E/(2r) ≥ 1000 ⇒ r ≤ E/2000 two E×H matrices: 2EH → 2r(E+H) ; factor EH/(r(E+H)) ≥ 1000
  • Distillation to halve the size: changing L (layers ≈ halve), E or H can each do it; V cannot (2VE is only ~0.3 B of 13 B). E is the hardest to change: it fixes the shape of every matrix and the embeddings, so the whole model must be retrained.
  • Quantisation 量化: map each weight to the nearest of 2ᵇ levels. For normally distributed weights, put more levels near 0 (NF4-style table) to minimise average error; a uniform table wastes levels in the rarely-used tails.
  • LoRA advantages: efficient training (few trainable params, less GPU memory), swap small adapters to serve multiple tasks, base model frozen (less forgetting). The choice of r trades training GPU memory against fine-tuned quality and depends on how much fine-tuning data there is.
