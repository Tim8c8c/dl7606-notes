01Topic guide課題導讀（中文解釋＋例子）

Lecture 2 · NN basics outline. Tap a topic for a Traditional Chinese explanation and an example. The English notes below go into exam detail.

1The perceptron感知器

把輸入加權求和再加偏置，經激活函數輸出：y = f(w₀ + w₁x₁ + w₂x₂)。它其實就是邏輯迴歸，等於在平面上畫一條直線分類。

例子OR 閘：w = (−50, 100, 100)。輸入 (0,0) → −50 → 0；(1,0) → 50 → 1。只要有一個輸入是 1，就超過 0。

2The neural network神經網絡（多層感知器）

把很多感知器排成多層：輸入層 → 隱藏層 → 輸出層。只要激活函數是非線性，多層就比單層強。

例子XOR 單層做不到，但用兩個隱藏神經元（x̄₁∧x₂ 和 x₁∧x̄₂）再 OR 起來就做到。

3Neural networks vs linear models神經網絡 vs 線性模型

線性模型只能畫一條直線（超平面）。一層隱藏層可圍出凸形區域，兩層可組成任意形狀的區域。

例子紅點在中間、藍點圍在外面：一條直線分不開，但三條直線圍成三角形（兩層網絡）就分得開。

4NN as a function approximator通用函數逼近器

σ(1000x − 400) 近似一個在 x = 0.4 的階梯。兩個階梯相減得出一個「凸起」，很多凸起並排就可以畫出任何函數。

例子想像用很多樂高積木（凸起）砌出一條山脈的輪廓：積木越細越多，輪廓越準確。

5Feedforward and inferencing前向傳播與推理

權重固定後，由第 0 層開始逐層計 s = xW + b、x = g(s)，直到輸出。這就是用訓練好的模型做預測。

例子x = [1, 2]，W = [[1],[1]]，b = 0，g = ReLU → s = 3 → 輸出 3。

6Backpropagation and training framework反向傳播與訓練框架

先前向計所有輸出，再由輸出層往回計 δ = ∂J/∂s，梯度 = 上一層輸出 × δ，最後更新權重。輸出層用 sigmoid + 交叉熵時 δ = h − y。

例子預測 h = 0.8，答案 y = 1 → δ = −0.2；如果上一層輸出 x = 0.5，則 ∂J/∂w = 0.5 × (−0.2) = −0.1，權重會增加 0.1α。

XOR needs two layers 異或需要兩層

No single line separates XOR (Minsky & Papert, 1969). Build it from gates: x₁ ⊕ x₂ = (x̄₁ AND x₂) OR (x₁ AND x̄₂). Folding the NOT into the weights: hidden unit A = (−150, −100, 200) computes x̄₁∧x₂, hidden unit B = (−150, 200, −100) computes x₁∧x̄₂, output = OR = (−50, 100, 100).

  • Linearly separable 線性可分: a hyperplane w₀ + w₁x₁ + … + wₙxₙ = 0 splits the classes. The weights are the line. For the line to separate OR: w₀ < 0, w₀+w₁ > 0, w₀+w₂ > 0.
  • Decision regions: 1 layer → half-plane; 2 layers → convex region; 3 layers → arbitrary region.
  • "Stacking linear perceptrons is still linear" is wrong once the activation is non-linear. NOT, AND, OR form a complete set, so a NN can compute any of the 2⁴ = 16 two-input logic functions.

03NN as a universal function approximator通用函數逼近器

σ(1000x − 400) is almost a step at x = 0.4. Subtracting a second step at 0.6 gives a "bump" of height y on [0.4, 0.6]. Add bumps side by side to draw any function. So two layers with enough neurons can approximate any measurable function to any accuracy; the network can be quite shallow.

bump on [w, w+Δ] with height y: y·σ(1000x − 1000w) − y·σ(1000x − 1000(w+Δ))

04Forward pass and backpropagation前向傳播與反向傳播

Forward: s⁽ˡ⁾ = x⁽ˡ⁻¹⁾W⁽ˡ⁾ + b⁽ˡ⁾ , x⁽ˡ⁾ = g(s⁽ˡ⁾) , h = x⁽ᴸ⁾ Output δ: δᵢ⁽ᴸ⁾ = g'(sᵢ⁽ᴸ⁾) · ∂J/∂h sigmoid + binary cross-entropy ⇒ δ⁽ᴸ⁾ = h − y (softmax + CE gives the same) Hidden δ: δᵢ⁽ˡ⁾ = g'(sᵢ⁽ˡ⁾) · Σⱼ wᵢⱼ⁽ˡ⁺¹⁾ δⱼ⁽ˡ⁺¹⁾ matrix: δ⁽ˡ⁾ = g'(s⁽ˡ⁾) ∘ δ⁽ˡ⁺¹⁾W⁽ˡ⁺¹⁾ᵀ Gradient: ∂J/∂wᵢⱼ⁽ˡ⁾ = xᵢ⁽ˡ⁻¹⁾ · δⱼ⁽ˡ⁾ matrix: ∂J/∂W⁽ˡ⁾ = x⁽ˡ⁻¹⁾ᵀ δ⁽ˡ⁾ , ∂J/∂b⁽ˡ⁾ = δ⁽ˡ⁾ Update: wᵢⱼ⁽ˡ⁾ ← wᵢⱼ⁽ˡ⁾ − α · xᵢ⁽ˡ⁻¹⁾ δⱼ⁽ˡ⁾

Why h − y? ∂J/∂h = (h − y) / (h(1 − h)) and σ'(s) = h(1 − h); they cancel.

Training framework 訓練流程

  1. Initialise weights randomly.
  2. Feed a (mini-)batch into layer 0.
  3. Forward: compute all x⁽ˡ⁾.
  4. Stop if the error is acceptable.
  5. Backward: compute all δ⁽ˡ⁾ from L down to 1.
  6. Update every weight, repeat.

Computation-graph gates (for numeric backprop questions)
  • Add gate copies the upstream gradient to both inputs.
  • Multiply gate: each input gets upstream × the other input.
  • Sigmoid: upstream × σ(1 − σ).
  • ×2 node after σ: doubles every gradient flowing back through it.
  • Branches that merge: add their gradients.
中文重點

單一感知器只能做線性可分問題（OR、AND），XOR 需要隱藏層。兩層網絡可逼近任何函數。反向傳播：先前向計算每層輸出，再由輸出層往回計算 δ = ∂J/∂s，權重梯度 = 上一層輸出 × δ。Sigmoid＋交叉熵時，輸出層 δ = h − y。

Exam pattern 考點

  • May 2024: name the output activation (softmax) and cost (cross-entropy) for 10-class classification; give the dimensions of s, W, b; write ∂J/∂W₂ = x₁ᵀδ₂, ∂J/∂b₂ = δ₂, ∂J/∂W₁ = x₀ᵀδ₁.
  • C-section papers: run forward and backward numbers through a small computation graph, truncating to 2 decimals.
