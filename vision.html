1Visualising and understanding CNNs理解 CNN 在看甚麼

遮擋敏感度：用灰色方塊遮住圖片不同位置，看正確類別機率下降多少；梯度上升：固定權重，改圖片令某神經元最活躍；最大激活圖塊：找令某神經元最興奮的圖塊。

例子遮住狗的臉後「狗」的機率由 0.9 跌到 0.2 → 模型靠狗臉判斷；如果幾乎不變，模型可能靠背景（草地）作弊。

2Object localisation物件定位

除了分類，還要輸出邊界框：y = (p_c, b_x, b_y, b_h, b_w, c₁, c₂, c₃)。p_c 表示有沒有物件；損失 = 分類誤差 + 框的誤差。

例子圖中有一架車：p_c = 1, b_x = 0.5, b_y = 0.7, b_h = 0.3, b_w = 0.4，c₂（車）= 1。

3Object detection (sliding windows, R-CNN, YOLO)物件偵測

要找出圖中所有物件。滑動窗口逐格分類太慢，可把全連接層改成卷積一次過計算；R-CNN 系列先提出候選區域再分類（兩階段、較準）；YOLO 單次輸出所有框（快，適合即時）。

例子28×28 圖用為 14×14 設計的網絡卷積化：輸出 8×8 → 等於 64 個步幅 2 的窗口，一次過算完。

4Semantic segmentation (U-Net)語義分割

每個像素都標類別，不用框。U-Net：編碼器縮細圖、加通道；解碼器放大、減通道；跳接把編碼器細節傳給解碼器，令邊界準確。

例子醫學影像中把腫瘤的每個像素標為 1，其餘為 0；自動駕駛把「可行駛路面」塗色。

5Adversarial images對抗樣本

對圖片加入人眼看不見的微小改動，令模型分錯類。FGSM：x_adv = x + ε·sign(∇ₓJ)。對抗訓練只對同一種攻擊有效。

例子熊貓圖加了少少雜訊，模型以 99% 信心說是「長臂猿」；停車標誌貼幾張貼紙，自動車當成限速牌。

02Visualising and understanding CNNs可視化

A. Occlusion sensitivity 遮擋敏感度

Slide a grey patch over the image; at each position record the probability of the correct class. Dark area in the heat map = covering it hurts most = the pixels the net relies on. If masking the dog's face doesn't hurt, the net is using the background, not the dog.

B. Gradient ascent 梯度上升

Fix all weights. Start from a blank/random image, then repeat: forward, backprop the neuron's value w.r.t. the pixels, nudge the image up the gradient. The result shows what that neuron "wants to see".

C. Maximally activating patches

Run many images, keep the top-k patches (LRFs) that fire a neuron most. Layer 1 → edges/colour blobs (filters are edge templates); deeper layers → textures, eyes, faces, with larger LRFs.

D. Feature-space neighbours

Nearest neighbours by pixels find look-alikes of different objects. Nearest neighbours by the last-layer 4096-d feature vector find the same object in different poses and colours.

03Localisation and detection定位與偵測

Localisation output: y = (p_c, b_x, b_y, b_h, b_w, c₁, c₂, c₃) p_c = 1 if an object is present (else background, other entries "don't care") loss = λ·L₁(classification) + L₂(bounding box) Pose: 16 key points → 32 coordinates, total loss = weighted sum of per-point losses YOLO: S×S grid, each cell predicts B boxes × (x, y, w, h, confidence) + C class probs output tensor S × S × (5B + C) confidence = Pr(object) × IoU IoU = area(A ∩ B) / area(A ∪ B)
  • Sliding windows: crop-classify at every position and size. Huge cost; a big stride is cheaper but misses objects. Objects may not fit a square.
  • Convert FC → conv: an FC layer reading a W×H×D volume = a conv with W×H×D filters (one filter per output neuron). Same params, same mults. Bigger input → spatial output map.
  • R-CNN (2014): selective search proposes ~2000 regions (fixed algorithm: colour, texture, edges) → CNN features on each → classify. Slow.
  • Fast R-CNN (2015): run CNN once on the whole image, crop proposals from the feature map.
  • Faster R-CNN (2016): a Region Proposal Network learns the proposals. Two-stage detectors are more accurate.
  • YOLO / SSD / RetinaNet: single-shot, one pass gives classes and boxes; real-time (self-driving, surveillance). Detection treated as regression. Weak on small, crowded, multi-scale objects. RetinaNet uses focal loss for class imbalance.
  • NMS 非極大值抑制: keep the box with the highest confidence, drop others with IoU above a threshold. AP = area under PR curve; mAP = mean over classes.
  • Semantic segmentation 語義分割: label every pixel (no boxes, no separate instances). U-Net: encoder shrinks size and adds channels; decoder upsamples and removes channels; skip connections copy encoder feature maps to the decoder to recover fine boundaries. Won ISBI 2015.

04Adversarial examples對抗樣本

A tiny, deliberate perturbation that makes the model mis-classify (panda → gibbon) while a human sees no change. Risks: a stop sign read as another sign, spam disguised as normal mail, a knife scanned as an umbrella.

FGSM (white-box, untargeted): x_adv = x + ε · sign( ∇ₓ J(θ, x, y) ) ε small → perturbation invisible ; gradient ASCENT on the loss of the true label Targeted: minimise loss( f(x + r), y_target ) + c·|r| over r (weights fixed) repeat until the net is fooled
  • Defence: adversarial training, i.e. add adversarial images labelled with the true class. It resists the attack you trained on but may not generalise to other attacks; the problem is not solved.
  • Not only NNs: linear models, SVMs, decision trees, k-NN are fooled too, and adversarial examples transfer between techniques. DNNs were the hardest to fool in the cross-technique table.
  • Humans have "adversarial examples" too: optical illusions (concentric circles seen as spirals).
