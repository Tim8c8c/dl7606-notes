Batch-size questions (May 2024)
  • Small batches: bigger batch → less noisy gradient → fewer iterations to reach target loss.
  • Large batches: gradient estimate is already accurate, so more examples add little; iterations barely change (diminishing returns).
  • Test error lower than training error? Dropout/regularisation active only during training, an easy or small test set, data leakage, or train loss averaged over an epoch while weights improved.

02Vanishing gradient and zero-centring梯度消失與零中心

  • Vanishing gradient: δ⁽ˡ⁾ = g'·(Σ w δ⁽ˡ⁺¹⁾) = g'·w·g'·w·… With sigmoid, g' ≤ 0.25, so δ shrinks geometrically going back. Early layers barely learn.
  • Not zero-centred: if every input xᵢ to a neuron is positive (sigmoid outputs), the gradients xᵢδ all share the sign of δ. All weights rise together or fall together → zig-zag path to the optimum.

04Learning rate, momentum, adaptive methods學習率、動量、自適應方法

Too small → many iterations, trapped in a local minimum. Too large → overshooting, no convergence.

Momentum: v_t = ρ·v_{t−1} − α∇J(w_{t−1}) , w_t = w_{t−1} + v_t ρ ≈ 0.9 Nesterov: v_t = ρ·v_{t−1} − α∇J(w_{t−1} + ρ·v_{t−1}) (look ahead, then correct → less overshoot) AdaGrad: G ← G + (∇J)² , w ← w − α/√(G+ε) · ∇J (rate shrinks forever) RMSProp: G ← βG + (1−β)(∇J)² , w ← w − α/√(G+ε) · ∇J (decay stops G exploding) Adam: m ← β₁m + (1−β₁)∇J ; v ← β₂v + (1−β₂)(∇J)² ; w ← w − α/√(v+ε) · m β₁=0.9, β₂=0.999, α=0.001, ε=1e−8

Adaptive methods keep a separate learning rate per parameter: large historical gradients → smaller steps. Momentum, Nesterov, AdaGrad, RMSProp and Adam all help with ill-conditioned loss surfaces (May 2024 D Q1.2).

05Overfitting and its cures過擬合與對策

Weight regularisation 權重正則化

Large weights → overfitting. Add the weight size to the cost:
J + λΣw² (L2, weight decay: shrinks all weights smoothly) or J + λΣ|w| (L1, drives many weights to exactly 0 → sparse model, feature selection).

Dropout 隨機失活

Randomly drop e.g. 50% of neurons each training step so the net cannot rely on any one neuron (an ensemble of thinned nets). At test time all neurons are used and outputs are scaled, so it behaves differently in training and testing.

Early stopping 提早停止

Watch validation error every epoch; stop when it stops decreasing. Epoch = one pass over the whole training set.

Data augmentation 數據增強

Crops, mirroring, colour jitter (AlexNet: random 227×227 crops of 256×256). More varied data → less memorisation.

Network distillation 知識蒸餾

Train a small student to reproduce the outputs of a large pre-trained teacher (which can generate lots of data). Use when data is scarce or the big model is too costly to deploy.

Batch normalisation 批次正規化

Per mini-batch: standardise (x − mean)/std, then scale by learned γ and shift by learned β. Each epoch is slower but accuracy is reached faster; no need to normalise inputs yourself.

normalisation: x' = (x − min) / (max − min) → [0,1] standardisation: x' = (x − mean) / std → mean 0, std 1 BatchNorm: y = γ · (x − μ_B)/σ_B + β (γ, β learned)
"Low training error, high test error" checklist (May 2024)

Reason: overfitting. Helps: ✓ data augmentation, ✓ stop training earlier, ✓ dropout (which is applied differently in training and testing), ✓ change the cost function by adding a regularisation term. Does not help: ✗ a bigger network (more overfitting), ✗ switching to ReLU (that addresses vanishing gradients, not overfitting).

中文重點

Sigmoid 導數最大只有 0.25，層數一多梯度便消失；ReLU 計算快、正區間無梯度消失，但有「死亡 ReLU」。學習率太細收斂慢、太大會震盪；動量 (momentum) 令更新保持方向，Adam 結合動量和 RMSProp。過擬合對策：L1/L2 正則化、Dropout、提早停止、數據增強。批次正規化令訓練更快收斂。
