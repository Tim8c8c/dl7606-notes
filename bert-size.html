01Revision: from RNN to attention溫故：由 RNN 到注意力

  • RNN: s_t = g(Wx_t + Us_{t−1}), y_t = g(Vs_t). Any input length with a fixed model size. Variants: LSTM, stacked, bidirectional. Uses: NER (many-to-many), sentiment (many-to-one), language model (one-to-many), translation (many-to-many).
  • Word embedding: a learned real-valued vector encoding a word's meaning, so words close in the vector space have similar meanings (features like royalty, gender, wealth, age). Built by CBOW / Skip-gram; ELMo gives context-sensitive vectors. Vector-space models also power recommenders (Taobao) and search (SMART).
  • Seq2Seq attention (the bridge to Q, K, V): the decoder state s_{t−1} is the query, the encoder states hᵢ are the keys and values. e_ti = a(s_{t−1}, hᵢ), α_ti = softmax(e_ti), context c_t = Σ α_ti hᵢ.

02Attention, step by step注意力四步曲

  1. Create Q, K, V: three separate linear layers with learned weights. Each token's embedding Eᵢ gives Qᵢ = EᵢW_Q, Kᵢ = EᵢW_K, Vᵢ = EᵢW_V.
  2. Similarity: Q (N×d) × Kᵀ (d×N) = N×N matrix of dot products. Row j = how much token j's query matches every key.
  3. Normalise: divide by √d (raw dot products grow with dimension 64, 512…; dividing keeps the variance at 1), add the mask, softmax each row ("sharpens" attention).
  4. Weighted sum: multiply the weights by the value vectors: zᵢ = Σⱼ softmax(qᵢ·kⱼ/√d)·vⱼ.
Worked example: "tall green creature"

Embeddings (E = 2) and weights (d = 2):

X = tall [1, 0] W_Q = [[1,0],[0,1]] (identity) green [0, 1] W_K = [[0,1],[1,0]] (swap) creature [1, 1] W_V = [[1,0],[0,2]]

Step 1 · Q = XW_Q, K = XW_K, V = XW_V

Q K V tall [1,0] [0,1] [1,0] green [0,1] [1,0] [0,2] creature [1,1] [1,1] [1,2]

Step 2 · QKᵀ (row = query, column = key)

tall green creature tall 0 1 1 green 1 0 1 creature 1 1 2

"creature" matches itself most (score 2).

Step 3 · ÷ √2 then softmax each row

tall green creature tall 0.198 0.401 0.401 green 0.401 0.198 0.401 creature 0.248 0.248 0.504 (each row sums to 1)

Step 4 · Z = A·V

z_tall = 0.198·[1,0] + 0.401·[0,2] + 0.401·[1,2] = [0.599, 1.604] z_green = [0.802, 1.198] z_creature = 0.248·[1,0] + 0.248·[0,2] + 0.504·[1,2] = [0.752, 1.504]

Every word now carries context from the others.

Step 5 · With a decoder (look-ahead) mask: add −∞ above the diagonal before softmax.

tall green creature tall 1 0 0 green 0.670 0.330 0 creature 0.248 0.248 0.504 z_tall = [1, 0] z_green = [0.670, 0.660] z_creature unchanged

"tall" can only see itself; the last token sees everything, so its row doesn't change.

Multi-head attention 多頭注意力

  • Split the embedding across heads: query size d = E / number of heads (e.g. E = 512, 8 heads → d = 64).
  • Each head has its own Q, K, V and its own N×N attention matrix, so different heads capture different relationships (gender, number, adjective, action…). Outputs are concatenated back to E.
  • Formula: softmax((QKᵀ + mask)/√d)·V, repeated for each head.

Attention masks 遮罩

Padding mask

Encoder self-attention and encoder–decoder attention: sentences have different lengths, so pad positions get −∞ (zero attention).

Look-ahead mask

Decoder self-attention: stop the decoder "peeking" at later target words when predicting the next word. Masked entries = −∞ → softmax gives 0.

03Sparse attention: DSA and MSA稀疏注意力

Observation: for any query, only a few tokens matter; about 90% of attention weights are near zero. Full attention costs O(L²) dot products for context length L.

DeepSeek Sparse Attention (DSA, Dec 2025)

  • A small, fast "lightning indexer" learns to predict which tokens full attention would pick: the top-k (k = 2048).
  • Attend to those k only: O(L²) → O(Lk).
  • Inference cost cut by >80%, ~20× less KV cache, scales past 1M tokens.

MiniMax Sparse Attention (MSA, Jun 2026)

  • Index branch: DSA-style scoring of KV blocks of 128 tokens (max pooling), keep top-k = 16 blocks.
  • Main branch, hardware-aware: decoding is memory-bandwidth bound (loading the KV cache). Contiguous blocks load faster than scattered tokens.
  • Asks "for this context block, which words matter?" instead of per word. 28.4× less attention compute at 1M context.
e.g. L = 128,000, k = 2,048 : per query 128,000 → 2,048 dot products (62.5× fewer)

04Feed-forward block and why transformers work前饋層與 Transformer 優勢

Feed-forward network (FFN)

  1. Linear transformation (dense layer)
  2. Activation (non-linearity)
  3. Dropout (prevents overfitting)
  4. Layer normalisation (stabilises, speeds training)

Why it matters: learns complex patterns, versatile, scalable (each token independent → parallel), simple and efficient (matrix multiply + activation).

Why transformers beat LSTMs

LSTMs (standard before 2017) capture dependencies of only ~7–15 tokens.

  1. Variable-size embedding: N×E grows with input, instead of a fixed-size RNN state, so no information is squeezed out.
  2. Direct interaction between any two tokens; RNN interaction depends on their distance.
  3. Parallelisable over all token pairs.

Summary: the encoder starts with an embedding for each word, builds Q, K, V from it, and computes a new, context-aware embedding with attention. The decoder generates the output word by word using (1) the encoder's representation and (2) its own last output.

05BERTBERT：雙向 Transformer 編碼器

Bidirectional Encoder Representations from Transformers (Google, 2018). Uses only the transformer encoder. (ELMo and BERT are both Sesame Street characters.)

Pre-training task 1: Masked LM

  • Mask 15% of words; predict them from the unmasked words on both sides (CBOW-like).
  • Classification layer on the encoder output → multiply by the embedding matrix → vocabulary-size scores → softmax.
  • Better than next-token prediction because it sees the whole context.

Pre-training task 2: Next Sentence Prediction

  • Pairs of sentences: [CLS] at the start, [SEP] after each sentence.
  • 50% true next sentence, 50% random; binary classifier gives P(IsNext) via softmax.
  • Helps tasks about sentence relationships (QA, entailment).
  • RoBERTa drops NSP and uses more data with dynamic masking.

What filling in a mask teaches: facts (HKU is in ___ → Pokfulam), syntax (I put ___ fork down → the/a), coreference (the woman… over ___ shoulder → her), semantics, sentiment, reasoning (Beth later left the ___ → kitchen), arithmetic (3 × 9 = ___).

BERT for word embeddings 上下文詞向量

  • Every layer's output per token can be a word embedding; the last 4 layers work best: concatenate (4 × 768 = 3072) or sum (768).
  • "After stealing money from the bank vault, the bank robber was seen fishing on the Mississippi river bank." Three different vectors: cos(bank-vault, bank-robber) = 0.94, cos(bank-robber, river-bank) = 0.69. Context-dependent, unlike Word2Vec.

Fine-tuning BERT for tasks 微調

TaskInputWhat's added
Classification (sentiment, inference, similarity)[CLS] sentence [SEP]Classification layer K×H on the [CLS] hidden state (K labels, H hidden size) + softmax

Most hyper-parameters stay as in pre-training; only a small layer is added. A full QA system = query processing (keywords by part of speech) → document retrieval → passage retrieval → answer extraction with BERT.

06Tokenization分詞：WordPiece / BPE

  • Units: sentence, word, character, or subword (balance between word and character). Byte-Pair Encoding or WordPiece split by frequency.
  • "embeddings" → em##bed##ding##s. "##" means "continues the previous piece".
  • BERT vocabulary ≈ 30,000: whole words; word-initial subwords; "##" subwords; single characters.
  • Algorithm: whole word in vocab? → else largest possible subwords from the left → last resort, single characters (so any word can be represented).
  • Advantages: smaller vocabulary (smaller model) and unseen words still work: antidisestablishmentarianism → anti · dis · establish · ment · arian · ism.

07BART and the three model familiesGPT · BERT · BART

BART (Bidirectional and Auto-Regressive Transformers): BERT-style bidirectional encoder + GPT-style left-to-right decoder. Trained as a denoising autoencoder: corrupt the text, reconstruct the original (cross-entropy). Corruptions: token masking, token deletion, sentence permutation, document rotation, text infilling (spans with Poisson-distributed lengths each replaced by one [MASK]). Fine-tuned for classification, token tagging, generation, translation.

Recall check即時測驗

Why divide QKᵀ by √d?

Large scores make softmax nearly one-hot with tiny gradients.

E = 768 with 12 heads. Query size d per head?

d = E / heads = 768 / 12.

The decoder's look-ahead mask sets future scores to…

softmax(−∞) = 0, so future words get no attention.

BERT's two pre-training tasks are…

NSP uses 50% real next sentences, 50% random.

BERT input embedding is the sum of…

Segment embedding (0s/1s) tells the two sentences apart.

For question answering, BERT learns…

P(start = i) = softmax(S·Tᵢ), P(end = i) = softmax(E·Tᵢ).

Approximate parameters of one transformer DECODER layer?

Self-attention + encoder–decoder attention (2 × 4E²) + FFN 2EH.

DeepSeek Sparse Attention reduces attention cost from…

Each query attends only to the top-k (k = 2048) tokens chosen by a lightning indexer.

BART is…

Bidirectional encoder + autoregressive decoder; reconstructs corrupted text.
