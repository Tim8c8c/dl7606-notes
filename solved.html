01Dec 2025 Q5 · Attention by hand (18 marks)

Q(cat) = [1,0,1]; K(chases) = [1,1,0], V = [0.5,0,0.5]; K(mouse) = [0,1,1], V = [1,0.5,0]. Scores, softmax, output.

Show answer
(a) score(cat, chases) = 1·1 + 0·1 + 1·0 = 1 score(cat, mouse) = 1·0 + 0·1 + 1·1 = 1 (b) softmax(sᵢ) = e^(sᵢ) / Σⱼ e^(sⱼ) → e¹/(e¹+e¹) = 0.5 each (c) output = 0.5·[0.5, 0, 0.5] + 0.5·[1, 0.5, 0] = [0.75, 0.25, 0.25]

Interpretation: "cat" attends equally to "chases" and "mouse", so its new representation is an even blend of the action and the object it relates to. (If the question had said "scaled dot product", divide by √3 first; equal scores still give 0.5/0.5.)

04May 2025 Q6 · VGG, 1×1 bottleneck, ResNet, GoogLeNet (24 marks)

Show answer
  • (a) After one 3×3 layer each output sees 3×3; a second 3×3 layer sees 3 neighbouring 3×3 windows → 5×5; a third → 7×7.
  • (b) Parameters per C→C layer: three 3×3 layers = 3·9C² = 27C² vs one 7×7 = 49C² (45% fewer), plus three non-linearities.
  • (c) Padding 1, stride 1.
  • (d) 28·28·128 · 3·3·192 = 173,408,256 mults.
  • (e) 1×1: 28·28·64·192 = 9,633,792; then 3×3: 28·28·128·3·3·64 = 57,802,752; total 67,436,544. Technique: 1×1 convolution / bottleneck layer (from Inception).
  • (f) Saves 105,971,712 mults, about 61%.
  • (g) ResNet: residual (skip) connections, learning F(x) = H(x) − x.
  • (h) GoogLeNet: auxiliary classifiers in the middle that inject gradient, plus 1×1 bottlenecks and global average pooling to stay efficient.

05Dec 2024 Q3 · Skip connection gradient (15 marks)

s = Wᵢxᵢ + bᵢ, aᵢ₊₁ = σ(sᵢ), xᵢ₊₁ = aᵢ₊₁ + xᵢ. Given δᵢ₊₁ = ∂J/∂xᵢ₊₁, find δᵢ = ∂J/∂xᵢ.

Show answer
δᵢ = ∂J/∂xᵢ = (∂xᵢ₊₁/∂xᵢ)ᵀ δᵢ₊₁ = Wᵢᵀ ( σ'(sᵢ) ∘ δᵢ₊₁ ) + δᵢ₊₁ with σ'(s) = σ(s)(1 − σ(s)) └──── through the layer ────┘ └ through the skip ┘

(b) Even when σ' ≤ 0.25 makes the first term tiny, the identity term passes δᵢ₊₁ back unchanged, so gradients reach early layers without shrinking. Over many blocks the gradient is a sum of paths, one of which is pure identity.

07May 2025 Q4 · LoRA (10 marks)

Show answer
  • (a) Full: 4E². LoRA: 4(Er + rE) = 8Er. Need 4E²/(8Er) = E/(2r) ≥ 1000 → r ≤ 5120/2000 = 2.56 → r = 2.
  • (b) Full: 2EH. LoRA: 2r(E + H). Need EH/(r(E+H)) ≥ 1000 → r ≤ 5120·13824/(1000·18944) = 3.74 → r = 3.
  • (c) A, C, D (training GPU memory, amount of fine-tuning data, output quality). Inference GPU is unaffected once A·B is merged into W.
  • (d) A and C (efficient training; one base model with small swappable adapters for many tasks). B is arguable: fewer trainable parameters lowers, but does not prevent, overfitting.

10Dec 2025 C Q3 · RNN for running variance (30 marks)

Show answer

State sₜ = (Sₜ, Qₜ, cₜ) = (Σx, Σx², count), update sₜ = W xₜ + U sₜ₋₁ + b, output rₜ = Qₜ/cₜ − (Sₜ/cₜ)².

  • (a) cₜ = t.
  • (b) x ∈ {0,1} (so x² = x): W is 3×1 = [1; 1; 0], U = I₃ (3×3), b = [0; 0; 1].
  • (c) x ∈ {0,2} (x² = 2x): W = [1; 2; 0], U = I₃, b = [0; 0; 1].
  • (d) x ∈ {1,2} (x² = 3x − 2): W = [1; 3; 0], U = I₃, b = [0; −2; 1].

11Dec 2025 C Q2 · Checkerboard CNN (30 marks)

Show answer
  • (a) Conv 2×2, stride 2 on 26×26 → 13×13×2.
  • (b, c) Sum-pool sizes 13 →(P=1) 7 →(P=1) 4 → 2 → 1, so k = 4; second and third pooling paddings are 1 and 0.
  • (d) Filters [[1,−1],[−1,1]] and [[−1,1],[1,−1]]. Each 2×2 block of a checkerboard gives exactly 2 for one filter (its maximum possible value); any other block gives less.
  • (e) Zero padding adds nothing, so the summed value for a perfect board is 169 × 2 = t = 338.

12Dec 2024 C Q3 · Card game MDP (30 marks)

Show answer (parts a, b)
  • (a) Stand on 3: win if y ∈ {1,2} (2/3) or y = 3 and heads (1/6) → r = 5/6.
  • (b) Values: stand on 1 = 1/6, stand on 2 = 1/3 + 1/6 = 1/2, stand on 3 = 5/6. Hit on 2 = (1/3)(5/6) = 5/18 < 1/2. Hit on 1 = (1/3)(1/2) + (1/3)(5/6) = 4/9 > 1/6. Optimal policy HSS.
